# Сайт-поздравление для Вики 🎂💜

Готовый сайт — один файл **`index.html`**. Открывается в любом браузере, полностью работает на телефоне.

## Как посмотреть
- **На компьютере:** двойной клик по `index.html`.
- **На телефоне:** нужна ссылка или сам файл, открытый в браузере (варианты ниже).

## Фото
Положите фотографию рядом с `index.html` и назовите её **`vika.jpg`** — сайт сам вставит её в рамку-полароид (кадрируется 4:5).
Пока фото нет, в рамке показывается стилизованный смартфон vivo.

## Что внутри
- Обратный отсчёт до 24 ноября. С 00:00 24-го он переключается: пишет «Праздник уже идёт 🎉» и показывает, сколько длится праздник.
- Кнопка **«Запустить праздник»** — включает музыку и конфетти.
- Музыка синтезируется прямо в браузере (Web Audio), никаких mp3-файлов не нужно. Включить/выключить можно круглой кнопкой в правом верхнем углу или кнопкой «♪ Музыка» в футере.
- Письмо, шуточный «топ вещей в жизни Вики», подарок с **22 пожеланиями** и полароид со смартфоном vivo (или вашим фото, если положить `vika.jpg`).
- Конфетти и сердечки, уважение к `prefers-reduced-motion`, safe-area для iPhone.

## Как передать Вике
1. **Ссылка (удобнее всего):** выложить папку на любой статический хостинг — Netlify Drop (перетащить папку), GitHub Pages, Vercel, Cloudflare Pages. Получится ссылка, которую можно открыть с телефона.
2. **Файл:** отправить `index.html` в мессенджере. Не все мессенджеры открывают html-файлы — иногда он скачивается как документ.
3. **Локальная сеть:** в этой папке запустить `python -m http.server 8000`, затем на телефоне (тот же Wi-Fi) открыть `http://<IP-компьютера>:8000`. Может потребоваться разрешение в брандмауэре Windows.

## Что легко поменять
- **Текст письма** — секция `<section class="block reveal" id="letter">`.
- **22 пожелания** — массив `wishes` в самом низу файла.
- **Дата и возраст** — поиск по `24 ноября`, `2026`, `22 года` в тексте.
- **Цвета** — переменные `--lav-*`, `--pink`, `--yellow`, `--mint` в начале `<style>`.

## Проверено
Chrome, эмуляция iPhone 390×844 и 320×568: нет горизонтального скролла, модалка и кнопки помещаются, JS-ошибок нет.
